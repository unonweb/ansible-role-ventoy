ATTENTION
=========

1. Download current release from: https://sourceforge.net/projects/ventoy/files/
2. Then place it into this role's file directory
3. Set `ventoy_archive_src` variable accordingly when using this role

Ventoy archives contain a top level directory named like `ventoy-1.1.10`. 
As I don't know a way to avoid the creation of this version directory we accept that a new directory is created for each version.
Furthermore we have to guess the name of this top level directory in order to set the path to the executable.
